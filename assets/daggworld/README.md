# DAGGWORLD Designs

Place the official DAGGWORLD clothing design images in this folder.

## Naming

Use descriptive filenames so the README slideshow can identify each design automatically.

Examples:

- `black-hoodie.png`
- `white-tee-front.png`
- `white-tee-back.png`
- `red-tracksuit.png`
- `daggworld-logo.png`
- `collection-01.jpg`

You can use `.png`, `.jpg`, `.jpeg`, or `.webp`.

**Do not rename the images after uploading unless necessary.** The final slideshow will be built around the actual filenames that are present here.

When all designs have been uploaded, tell me to start. I will inspect the folder and build the animated DAGGWORLD showcase from the real files.
